Rust · whisper.cpp

Episode Transcribe

Batch-transcribe tabletop episode MP4s into SRT, TXT, and optional speaker-tagged ASS subtitles using whisper.cpp and sherpa-onnx diarization.

View on GitHub

Features

  • Directory-oriented CLI — outputs next to each video
  • CPU or CUDA builds via install scripts
  • Speaker diarization with sherpa-onnx
ReleasesSource

Install

git clone https://github.com/PiyushMishra318/transcribe.git
powershell -File scripts/install.ps1   # Windows GPU
./scripts/install.sh --cpu-only      # Linux/macOS
